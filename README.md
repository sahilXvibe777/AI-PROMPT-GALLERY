# 🚀 AI Prompt Gallery

An interactive and curated repository of high-utility AI prompts designed to streamline workflows, enhance creativity, and improve prompt engineering efficiency.

🔗 **Live Demo:** [https://sahilxvibe777.github.io/AI-PROMPT-GALLERY/](https://sahilxvibe777.github.io/AI-PROMPT-GALLERY/)

---

## 🌟 Features
- **Curated AI Prompts:** Categorized prompts for writing, coding, productivity, and learning.
- **User Analytics:** Integrated with **Google Analytics 4 (GA4)** to track user engagement and popular prompt views.
- **Clean UI:** Responsive and minimal design for effortless browsing on all devices.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
- **Analytics:** Google Analytics 4 (GA4)
- **Deployment:** GitHub Pages

## 🚀 Quick Start & Usage
1. Open the [Live Demo Link](https://sahilxvibe777.github.io/AI-PROMPT-GALLERY/).
2. Browse through the available categories.
3. Select and copy the prompts directly to use with AI models like ChatGPT, Claude, or Gemini.
